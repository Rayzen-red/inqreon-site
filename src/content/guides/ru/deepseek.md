DeepSeek — четвёртый по посещаемости ИИ-чат-бот в мире. В октябре 2026 года Similarweb насчитал у него около 372,8 млн визитов; впереди только ChatGPT, Gemini и Claude, пишет [Momentic](https://momenticmarketing.com/blog/top-ai-chatbots). Притягивает он простым набором: толковый ассистент без подписки, модели, которые можно скачать, и API заметно дешевле, чем у большинства конкурентов.

Есть и подвох, и он прописан в собственной политике конфиденциальности DeepSeek. Разбираем обе стороны.

## Что это такое

DeepSeek — китайская ИИ-компания из Ханчжоу. У неё три продукта:

- **Чат-ассистент** в браузере на chat.deepseek.com и в мобильных приложениях. Вход — по почте, телефону, через Google или Apple.
- **API** для разработчиков с двумя актуальными моделями: deepseek-flash (версия V4.1-Flash-1017) и deepseek-v4-pro (V4-Pro-0813).
- **Открытые веса.** DeepSeek выкладывает модели на Hugging Face. В [карточке V4-Pro-0813](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro-0813) указана лицензия MIT — она позволяет компаниям запускать модель на своих серверах.

На [официальном сайте](https://www.deepseek.com/en) сказано, что последнее обновление Flash лучше справляется с разработкой проектов, а API теперь умеет искать в интернете и открывать страницы.

## В чём он силён

**Цена.** По [странице цен API](https://api-docs.deepseek.com/quick_start/pricing), модель Flash стоит $0,30 за миллион входных токенов и $1,20 за миллион выходных в часы пик, а в остальное время — вдвое дешевле. Для приложений, которые гоняют через модель много текста, это меняет всю экономику.

**Открытые веса.** Модели DeepSeek можно запустить у себя. Это важно командам, которым нельзя отправлять данные во внешний сервис, и исследователям, которые хотят изучить и дообучить модель.

**Длинный контекст.** В документации API заявлено окно в 1 млн токенов и до 384 тыс. токенов на выходе.

**Удобство для разработчиков.** API принимает запросы и в формате OpenAI, и в формате Anthropic. Если ваш код уже работает с одним из них, переезд сводится в основном к смене адреса и ключа.

## Где подводит

**Куда уходят данные.** В [политике конфиденциальности](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html) сказано: сервисом управляет Hangzhou DeepSeek Artificial Intelligence Co., Ltd., и персональные данные собираются, обрабатываются и хранятся в КНР. Там же написано, что введённые вами данные могут идти на обучение моделей, и есть право от этого отказаться. Для всего конфиденциального — файлов клиентов, данных о здоровье или финансах — это главная причина подумать дважды. Открытые веса на своём железе снимают вопрос, но требуют технической работы.

**Меньше возможностей в приложении.** Рядом с ChatGPT или Gemini чат выглядит аскетично. Генерацию картинок и видео для обычных пользователей сайт не предлагает, а работу с изображениями в API поддерживает только модель Flash.

**Цены в часы пик.** Тарифы API удваиваются в часы пик: с 01:00 до 04:00 и с 06:00 до 10:00 по UTC, с понедельника по пятницу. Пакетные задачи выгоднее запускать вне этих окон.

**Оговорка про точность.** DeepSeek сама пишет, что на фактическую точность ответов модели полагаться не стоит. Это верно для любого чат-бота, но здесь лучше понять буквально.

## Для чего он нужен

- Повседневные вопросы, помощь с текстами и задачи на рассуждение без подписки.
- Помощь с кодом и приложения на скромном бюджете API.
- Сильная модель на собственных серверах через открытые веса.
- Обработка больших объёмов текста, где цена за токен решает всё.

## Кому подходит

DeepSeek хорош для разработчиков и стартапов, которые считают каждый доллар в счёте за API, для команд, которым нужна модель на своём сервере, и для любопытных пользователей, которым нужно второе мнение рядом с основным ассистентом.

Плохо подходит тем, кто работает с конфиденциальными данными клиентов через облачное приложение, и компаниям, чьи правила запрещают отправлять данные на серверы в Китае.

## Тарифы и цены (на ноябрь 2026 года)

Платной подписки для обычных пользователей на сайте DeepSeek нет, чат просит только завести аккаунт. Актуальные условия приложения смотрите на [официальном сайте](https://www.deepseek.com/en).

API оплачивается по факту. Цены за миллион токенов со [страницы цен API](https://api-docs.deepseek.com/quick_start/pricing), проверено 15 ноября 2026 года:

| Позиция | deepseek-flash, пик | deepseek-flash, вне пика | deepseek-v4-pro, пик | deepseek-v4-pro, вне пика |
| --- | --- | --- | --- | --- |
| Вход, из кэша | $0,006 | $0,003 | $0,044 | $0,022 |
| Вход, не из кэша | $0,30 | $0,15 | $1,32 | $0,66 |
| Выход | $1,20 | $0,60 | $3,96 | $1,98 |

Поиск в интернете и открытие страниц — по $0,75 за 1000 обращений. Разбор файлов и распознавание текста — $0,225 за 1000 страниц. Баланс пополняется заранее, и DeepSeek оговаривает, что цены могут меняться.

## Плюсы и минусы

**Плюсы**

- рабочий чат без подписки;
- открытые веса под лицензией MIT;
- очень низкие цены на API и скидка вне часов пик;
- окно в 1 млн токенов и API, совместимый с OpenAI и Anthropic.

**Минусы**

- по политике конфиденциальности данные хранятся в Китае;
- введённое может идти в обучение, пока вы не откажетесь;
- меньше творческих и рабочих функций, чем у крупных американских ассистентов;
- в часы пик API стоит вдвое дороже.

## Короткий вывод

Для разработчиков DeepSeek — один из самых дешёвых способов поставить толковую модель за приложением, а открытые веса оставляют запасной выход: можно развернуть модель у себя. Для личных задач это хороший бесплатный ассистент, если речь не о чувствительных данных. Клиентские файлы и личные подробности в облачный чат лучше не отправлять.
