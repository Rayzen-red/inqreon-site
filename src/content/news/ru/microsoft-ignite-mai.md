17 ноября на конференции Ignite команда MAI в Microsoft выпустила то, что сама называет семейством из семи новых моделей, рассчитанных на работу по приемлемой цене. Главная модель для программирования — MAI Code 2. Microsoft пишет, что в среднем по четырём тестам повседневной корпоративной разработки Code 2 даёт 98% качества GPT-6.1 Sol примерно за 40% цены и 96% качества Claude Opus 5.5 за 5% цены.

Это сравнения самой Microsoft. Мы эти тесты не прогоняли.

## Семь моделей и где уже можно взять Code 2

В посте Microsoft в линейке такие модели: MAI Cyber 2 Flash, MAI Code 2, MAI Code 2 Flash, MAI Image 2.7, MAI Realtime 1, Dragon Copilot Transcribe на базе MAI Transcribe 2 и Decision 1.1. В том же тексте упоминается Maia 200, ускоритель второго поколения. Это уже не модель, а чип.

Microsoft прямо пишет, для чего Code 2 пока не предназначена. Компания говорит, что модели для кода «явно ещё не настроены» на более трудные задачи вроде фундаментальных научных исследований и очень длинной агентной работы. Их делали под повседневные задачи, которые Microsoft видит в GitHub Copilot. Четыре теста за цифрой 98% — это DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas и FrontierCode v1.1. В слепом сравнении вёрстки, по данным Microsoft, разработчики в 64% случаев предпочли MAI Code 2 модели GPT-6 Sol.

По словам компании, MAI Code 2 уже можно попробовать в GitHub Copilot. MAI Code 2 Flash, которую делают для частых коротких дел вроде пояснений, небольших правок и обычных исправлений, тоже есть в Copilot и в ограниченном предпросмотре Microsoft Foundry. Microsoft пишет, что Flash по качеству сопоставима с GPT-6 Luna при 65% цены и с Claude Haiku 5.5 при 20% цены, если смотреть на три из этих тестов по коду.

## Коротко о остальных моделях

Остальные модели собраны вокруг того же аргумента про цену. Microsoft утверждает, что Cyber 2 Flash превосходит качество GPT-6 Astra меньше чем за 2% стоимости задачи на тесте CyberGymE2E, а выходные токены у неё на 86% дешевле, чем у MAI Cyber 1.1 Flash. MAI Image 2.7, по данным компании, занимает первое место на Artificial Analysis в редактировании изображений и обходит GPT Image 2.6 Sunburst (max) за пятую часть цены. MAI Realtime 1, первая модель Microsoft для живого разговора голосом, начинается с $0,01 за минуту звука — так пишет сама компания. Decision 1.1, модель для маршрутизации запросов, описана как в 50 раз быстрее и в 79 раз дешевле GPT-Sol 6.1; ею, по словам Microsoft, уже пользуются 4 000 клиентов. Dragon Copilot Transcribe, утверждает компания, теперь расшифровывает все разговоры врача и пациента в Dragon Copilot: это 10 миллионов приёмов в месяц, а число ошибок в многоязычных сценариях снизилось вдвое.

И это тоже заявления самой компании.

## Что попробовать, если вы уже пишете код в Copilot

Если GitHub Copilot у вас уже стоит в редакторе, на этой неделе достаточно короткой проверки. Запустите MAI Code 2 на обычной правке или на дашборде и сравните с привычной моделью, в том числе по тому, сколько потом приходится исправлять самим. Длинные исследования и многочасовые агентные задачи лучше оставить модели, которую для этого собирали: Microsoft пишет, что Code 2 пока не такая.

Более дешёвая модель для кода может набросать большую часть приложения. Вход, оплату и боевой деплой она с вас не снимет — всё равно, начали вы в Copilot, Cursor, Lovable, Bolt или v0.
