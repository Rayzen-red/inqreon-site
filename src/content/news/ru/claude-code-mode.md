12 ноября в Claude Code, в версии 2.1.323, появился экспериментальный режим Code Mode. Обычно Claude отдельно запрашивает каждый вызов инструмента — Bash, Read или Edit — и только потом решает, что делать дальше. В Code Mode он пишет небольшой JavaScript, который делает эти вызовы, а Claude Code запускает этот скрипт в вашей сессии. Один скрипт может выполнить команды параллельно, подставить результат одной в следующую и вернуть модели только ту часть вывода, которая ей нужна.

По умолчанию режим выключен. В документации Anthropic прямо сказано, что его могут изменить или убрать в любом выпуске. Включается он так: в переменную окружения `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE` ставите `1` и запускаете `claude`, а при первом запуске подтверждаете запрос. Чтобы режим включался в каждой новой сессии, ту же переменную можно прописать в блоке `env` файла `~/.claude/settings.json`. В настройках конкретного репозитория Claude Code эту переменную игнорирует: клонированный проект сам режим за вас не включит. После перезапуска в начале сессии должна появиться строка, что Code Mode (experimental) включён. В переписке по-прежнему видны сами вызовы, например diff; JavaScript спрятан за Ctrl+O, в свёрнутой строке Code.

## Кто может им пользоваться, а кто нет

Требований здесь больше, чем в обычном обновлении Claude Code. Нужны версия 2.1.323 или новее, официальная сборка и интерактивная сессия `claude` в терминале. Режим работает с Claude Opus 5.5, Sonnet 5.5, Haiku 5.5 или Fable 5.2, если у вас подписка Claude или аккаунт в Console. Он не работает с `-p`, Agent SDK, панелью VS Code, приложением Desktop и облачными сессиями. Его также нельзя включить через шлюз, Amazon Bedrock, Claude в AWS, Google Cloud или Microsoft Foundry, и он недоступен организациям с конфигурацией HIPAA или с нулевым хранением данных. В Windows нужно установить Git for Windows. Часть настроек, в том числе помощник для API-ключа или выключенная телеметрия, тоже не даёт режиму запуститься.

Anthropic советует пробовать Code Mode на задачах, где много связанных вызовов: одна и та же правка в десятках файлов, поиск, который сначала нужно отфильтровать, или несколько независимых команд, которые можно запустить сразу. Если скрипт нельзя увести в фон, он останавливается через десять минут, и всё это время вы ждёте. Продолжить сессию Code Mode можно только в терминале и только с включённым режимом. Remote Control, Claude in Chrome и управление компьютером в этом режиме недоступны, а перенести сессию в Desktop или в фон нельзя.

## Короткий опыт, если ограничения вам подходят

Если вы и так работаете в терминале Claude Code и аккаунт подходит под требования, достаточно узкой проверки. В документации Anthropic для первого опыта предлагает, например, такое задание: прочитать все Markdown-файлы в проекте и выписать ссылки на локальные файлы, которых нет. Возьмите знакомый репозиторий, попросите Claude сделать работу с множеством мелких шагов, откройте расшифровку и прочитайте скрипт, который он написал. Если нужны команды агентов (agent teams), в документации указана версия 2.1.326 или новее. Для повседневного чата в VS Code режим лучше не включать. Организациям, которым эксперимент не нужен, в управляемых настройках можно поставить ту же переменную в `0`.

Более быстрые вызовы инструментов не заменяют просмотр diff и не запускают за вас вход и оплату. Если проект начинался в Cursor, Claude Code, Lovable, Bolt или v0, последняя миля по-прежнему за вами.
