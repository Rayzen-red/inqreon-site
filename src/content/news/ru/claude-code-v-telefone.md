20 ноября Anthropic начала выкатывать новый дизайн приложения Claude на iOS и Android. Внизу появились вкладки Чат, Проекты, Code и Артефакты, пишет The Verge со ссылкой на сообщение Дэниела Дестефаниса из Anthropic. Обновление вышло на день позже, чем похожий редизайн приложения ChatGPT с нижней панелью вкладок.

Главное здесь — вкладка Code. С телефона можно запустить облачную сессию с кодом, следить за ней, отвечать на вопросы Claude и направлять работу в новую сторону. Сессия может продолжаться, даже когда телефон уже в кармане. Это удобно, если вы и так работаете в Claude Code за столом и хотите проверить длинную задачу с дивана или из поезда.

## Телефон здесь пульт, а не компьютер

Документация Anthropic сразу очерчивает границы. Отдельного мобильного Claude Code нет, и код на телефоне не выполняется. Приложение Claude — это клиент. Оно может открыть облачную сессию, проект в облаке, сессию на вашем компьютере через Remote Control или, в некоторых случаях, приложение для компьютера через Dispatch.

Облачные сессии по умолчанию идут на инфраструктуре Anthropic, поэтому задача не останавливается, даже если ноутбук закрыт. Во вкладке Code вы выбираете репозиторий и ветку, описываете задачу и отправляете её. Сессии живут на всех устройствах: то, что начали на ноутбуке, можно разобрать с телефона, и наоборот. Можно попросить Claude следить за pull request и чинить падения CI или разбирать комментарии к ревью, когда они появляются.

Remote Control устроен иначе. Сессию Claude Code запускают на компьютере командой `claude remote-control` или `/remote-control`, а потом подхватывают в приложении. Выполнение и доступ к файлам остаются на вашей машине, поэтому компьютер должен быть включён. Если он уснёт, в документации сказано, что соединение восстановится, когда машина проснётся. Dispatch, которому задачу пишут сообщением в приложении, тоже управляет вашим компьютером и для новых пользователей недоступен.

Когда длинная задача заканчивается или Claude нужно ваше решение, может прийти пуш. Часть команд, которые работают только в терминале, например `/plugin` и `/resume`, из приложения не вызываются. Режим Bypass permissions с телефона тоже выбрать нельзя.

## Кто может пользоваться уже сегодня

Нужны приложение Claude и тот же аккаунт claude.ai, которым вы входите в Claude Code. Облачные сессии и Remote Control недоступны с ключом Anthropic Console и из сторонних площадок вроде Amazon Bedrock. Если вкладки Code нет, в документации сказано, что её может не быть на вашем тарифе или в организации.

По таблице доступности Anthropic облачные сессии работают на тарифах Pro, Max, Ultra и Team, а на Enterprise — при премиум-месте или месте Chat + Claude Code. Remote Control есть на Pro, Max и Ultra, а на Team и Enterprise его включает администратор. Dispatch требует Pro, Max или Ultra, новым пользователям его не дают, на Team и Enterprise его нет.

Если подходящий тариф и репозиторий на GitHub уже есть, для первого раза возьмите задачу, которую потом сами проверите: починить падающий тест, набросать небольшой патч, посмотреть CI. Не выкладывайте работу с телефона, не прочитав diff. Сессия, которую можно направить из поезда, всё равно остаётся черновиком, пока кто-то не проверит вход, оплату и деплой, который выдерживает нагрузку, — в Claude, Cursor, Lovable, Bolt или v0.
