On Nov. 17, at its Ignite conference, Microsoft's MAI team released what it calls a family of seven new models, priced to run at scale. The headline coding model is MAI Code 2. Microsoft says that, averaged across four benchmarks it uses for everyday enterprise coding work, Code 2 reaches 98% of the quality of GPT-6.1 Sol at about 40% of the price, and 96% of Claude Opus 5.5 at 5% of the price.

Those are Microsoft's comparisons. We have not run the tests.

## The seven models, and where Code 2 already is

The lineup in Microsoft's post is MAI Cyber 2 Flash, MAI Code 2, MAI Code 2 Flash, MAI Image 2.7, MAI Realtime 1, Dragon Copilot Transcribe (built on MAI Transcribe 2), and Decision 1.1. The same post also mentions Maia 200, Microsoft's second-generation AI accelerator, which is a chip, not a model.

Microsoft is explicit about what Code 2 is not for. It says the coding models are "explicitly not yet tuned" for harder problems such as fundamental science research and very long-horizon agentic work. They are meant for the everyday tasks Microsoft sees in GitHub Copilot. The four benchmarks behind the 98% claim are DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas, and FrontierCode v1.1. In a blind side-by-side evaluation of frontend work, Microsoft says developers preferred MAI Code 2 over GPT-6 Sol 64% of the time.

You can try MAI Code 2 in GitHub Copilot today, according to the post. MAI Code 2 Flash, aimed at high-volume work such as explanations, small edits, and routine fixes, is in Copilot as well, and in a limited preview in Microsoft Foundry. Microsoft says Flash matches the performance of GPT-6 Luna at 65% of the price and of Claude Haiku 5.5 at 20%, across three of those coding benchmarks.

## The rest of the family, in brief

The other models follow the same price argument. Microsoft says Cyber 2 Flash beats GPT-6 Astra's quality at less than 2% of the cost per task on the CyberGymE2E benchmark, and that its output tokens are priced 86% lower than MAI Cyber 1.1 Flash. It says MAI Image 2.7 is first on Artificial Analysis for image editing and outperforms GPT Image 2.6 Sunburst (max) at one-fifth the price. MAI Realtime 1, the company's first live speech-to-speech model, starts at $0.01 per audio minute, by Microsoft's account. Decision 1.1, a routing model, is described as 50 times faster and 79 times cheaper than GPT-Sol 6.1, and already used by 4,000 customers. Dragon Copilot Transcribe, Microsoft says, now handles all doctor-patient transcriptions in Dragon Copilot, covering 10 million encounters a month, and has halved error rates in multilingual workflows.

Again, these are the company's claims.

## What to try if you write code in Copilot

If GitHub Copilot is already in your editor, the useful experiment this week is a bounded one. Run MAI Code 2 on a routine change or a dashboard, and compare it with the model you usually use, including how much you have to fix. Leave the long research and multi-hour agent jobs to a model that was built for them; Microsoft says Code 2 is not that model yet.

A cheaper coding model can draft more of the app. It still will not take sign-in, payments, or production deploy off your hands, whether you started in Copilot, Cursor, Lovable, Bolt, or v0.
